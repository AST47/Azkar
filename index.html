سجل الإصدارات

١.٠إطلاق الموقع: كل الأذكار عبر سبع فئات، مع نظام ترتيب ثابت ووضع تعديل للمشرفين
١.١بادج تصنيف مميز لكل ذكر بصفحة "كل الأذكار"
١.٢إضافة ميزة العناوين لاستخدامها في بعض الأذكار والأدعية
١.٣إضافة خمس سور قرآنية كاملة (يس، الرحمن، الواقعة، الملك، الكهف) بتنسيق مميز
١.٤إمكانية عرض صور الرسم العثماني الأصلية لكل مقطع قرآني، بمتصفح صور بين الصفحات
٢.٠الانتقال من تخزين محلي لقاعدة بيانات (مزامنة حقيقية بين كل الأجهزة)
٢.١دعم العمل بدون إنترنت بعد أول تحميل
٢.٢زر "كل الأدعية" مستقل بالأعلى
٢.٣خط زمني بأيقونات (شروق ← شمس ← غيوم ← غروب ← هلال) بدل التبويبات العادية للتصنيفات الوقتية
٢.٤الصفحة تفتح افتراضياً على "الظهيرة" (منتصف اليوم)
٢.٥تحميل مسبق لصفحات القرآن التالية أثناء القراءة (بدون تأخير محسوس)
٢.٦صفحة "المتابعة اليومية" لتتبع الصلوات والأذكار وورد القرآن اليومي

استيراد / تصدير المحتوى

"تصدير" بيطلعلك كل المحتوى الحالي كـ JSON تقدر تنسخه وتعدل عليه. "استيراد" بيستبدل كل المحتوى الحالي بالنص يلي بتلصقه هون — تأكد إنه صحيح قبل ما تأكد.
